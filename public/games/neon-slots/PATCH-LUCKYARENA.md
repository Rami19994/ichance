# تعديل محلّي على حزمة اللعبة — اقرأه قبل تحديثها

اللعبة من <https://github.com/1stake/slot-machine-online-casino-game> (رخصة MIT)
ونسختها هنا مطابقة للنسخة المنشورة **عدا تعديلاً واحداً** في
`assets/js/main.js`.

> ⚠ إن أعدت تنزيل اللعبة من المصدر فستفقد هذا التعديل. أعِد تطبيقه.

## ما هو

محمّل اللعبة سلسلة متتابعة: كل صورة تُحمَّل، ومعالج `onload` الخاص بها يزيد
العدّاد ويجدول الخطوة التالية. آخر خطوة تحميل خلفية الماكينة `bg.png`،
وكودها الأصلي:

```js
container_bg.src = base + 'bg.png',
container_bg.onload = function () { loading_idx++; lbl_load_update(); next(); };
```

فيه أمران:

1. **`src` قبل `onload`** — مخالف للترتيب في كل مواضع التحميل الأخرى في
   الملف. (قِسْنا ذلك في Chrome: الحدث لا يضيع، لأن المتصفّح يجدوله مهمّةً
   لاحقة فلا يسبق نهاية الكتلة المتزامنة. فالخطر نظري لا عملي، لكن الترتيب
   الصحيح لا يكلّف شيئاً.)
2. **لا `onerror`** — وهذا خطر حقيقي: لو تعذّر تحميل `bg.png` مرّة واحدة
   (انقطاع، أو خطأ من الشبكة) ماتت السلسلة عند آخر خطوة وتجمّدت الشاشة على
   «LOADING…100%» بلا أي رسالة.

## التعديل المطبَّق

```js
container_bg.onload = container_bg.onerror = function () {
  if (this.__laStepDone) return;     // خطوة واحدة مهما تعدّدت الإشارات
  this.__laStepDone = true;
  loading_idx++; lbl_load_update(); next();
};
container_bg.src = base + 'bg.png';
if (container_bg.complete) container_bg.onload();
```

**الراية ليست زينة.** حين تكون الصورة في ذاكرة المتصفّح تصير `complete`
صحيحةً فور ضبط `src` بينما حدث `load` ما يزال في طابور المهامّ — قِسنا ذلك
هنا. فبدون الراية يُنفَّذ المعالج مرّتين وتنقسم سلسلة التحميل إلى سلسلتين.
(نسخة سابقة من هذا التعديل في تاريخ المستودع كانت بلا راية وتقع في هذا
الفخّ تماماً.)

## ما لا يجوز فعله

لا تُصلح شيئاً من هذا بتعديل `HTMLImageElement.prototype` من
`public/neon-slots.html`. جُرِّب وكان هو سبب التجمّد لا علاجه:

- الخاصية `onload` ليست ملكاً لـ`HTMLImageElement.prototype` بل
  لـ`HTMLElement.prototype`، فشرط `if (origOnloadDesc)` في ذلك «الإصلاح»
  كان يفشل بصمت وتبقى رايته غير معرّفة أبداً.
- فصار يستدعي `onload` يدوياً **فوق** الحدث الحقيقي: مرّتان لكل صورة
  (قياس مباشر: استدعاءان لصورة واحدة)، وتتفرّع سلسلة التحميل —
  **621 خطوة بدل 180**.

الإصلاح هنا جراحي وفي موضعه، بلا أثر على بقيّة الصفحة.

## التعديل الثاني: خطاف ربط المحفظة (Wallet Bridge Hook)

عند اكتمال إقلاع الماكينة (`loaded`) يتم تصدير نسخة الكائن إلى:
```js
window.__neonSlotInstance = _0x2fbefa;
if (typeof window.onNeonSlotsReady === 'function') window.onNeonSlotsReady(_0x2fbefa);
```
يسمح هذا لصفحة `neon-slots.html` بربط زر الدوران بمحرك السيرفر والتحقق من رصيد محفظة اللاعب وخصم الرهان وإيداع الأرباح ذرياً.
